# Security policy

Upserve distributes executable software. Keep upstream publishing credentials, signing infrastructure and downstream access control separate.

Do not disclose an exploitable vulnerability in a public issue. While this repository is private, contact an existing repository maintainer through an established private channel. Before public launch, maintainers must configure GitHub private vulnerability reporting or publish a verified disclosure address here. This project does not currently claim a security mailbox, response SLA or supported maintenance branches.

Include affected versions, a minimal reproduction, impact and a suggested mitigation without live credentials or signing keys. Avoid downloading or executing another application's artifacts during a report.
